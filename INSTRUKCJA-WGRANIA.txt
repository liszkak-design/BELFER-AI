ZAWARTOSC PACZKI
----------------
index.html                - cala strona (HTML + CSS + JS w jednym pliku)
robots.txt                - WERSJA PODGLADOWA (bez wpisu Sitemap)
robots-produkcja.txt      - wersja dla belfer-ai.pl, do podmiany przy publikacji
sitemap.xml               - mapa strony
.nojekyll                 - wylacza Jekyll na GitHub Pages
INSTRUKCJA-WGRANIA.txt    - ten plik

UWAGA: repozytorium jest ustawione pod PODGLAD na GitHub Pages.
Kazdy plik .html ma <meta name="robots" content="noindex, nofollow,
noarchive"> - strona nie trafi do Google. Przed publikacja na
belfer-ai.pl usun te znaczniki i podmien robots.txt zawartoscia
robots-produkcja.txt. Szczegoly w README.md.

KROK 1 - WGRANIE
----------------
Wrzuc wszystkie pliki do glownego katalogu domeny:
public_html/ albo htdocs/ albo www/
Strona dziala od razu. Nie wymaga PHP, bazy danych ani Node.

Bez hostingu (darmowo, 30 sekund):
- Netlify Drop     -> app.netlify.com/drop  (przeciagnij pliki)
- Cloudflare Pages -> pages.cloudflare.com
- GitHub Pages     -> repo + Settings > Pages

Wlacz HTTPS (Let's Encrypt) - u wiekszosci hostingow jedno klikniecie.

KROK 2 - PODLACZ FORMULARZ (NAJWAZNIEJSZE)
------------------------------------------
UWAGA: w index.html jest juz wpisany adres
https://formspree.io/f/TWOJE_ID - MUSISZ podmienic TWOJE_ID
na wlasne, inaczej formularz nadal nie zadziala.

Formularz obecnie pokazuje tylko komunikat, NIE wysyla zgloszen.

Formspree (darmowy plan, 50 zgloszen/mies.):
1. formspree.io -> nowy formularz -> skopiuj ID
2. w index.html znajdz:
   <form class="lead" action="#" method="post" onsubmit="alert(...);return false;">
3. zamien na:
   <form class="lead" action="https://formspree.io/f/TWOJE_ID" method="POST">
   (usun caly atrybut onsubmit)

Alternatywy: Tally.so, Web3Forms, Getform.

TECHNICZNIE
-----------
- Jeden plik, zero frameworkow, tylko czysty JavaScript.
- Google Fonts laduja sie WYLACZNIE po zgodzie w banerze cookies.
- Dane strukturalne JSON-LD: SoftwareApplication + FAQPage.
- Responsywnosc: 5 progow (1024 / 900 / 760 / 600 / 520 px),
  menu mobilne z hamburgerem, tabele przewijane poziomo.
- Dostepnosc: obsluga prefers-reduced-motion, aria na menu,
  brak efektow hover na ekranach dotykowych.
- Arkusz do druku (naglowek, makiety i formularz sie nie drukuja).

HISTORIA POPRAWEK
-----------------
BANER COOKIES (31.07.2026)
- Google Fonts nie laduja sie bez zgody (byl to wyciek IP do Google
  mimo deklaracji zgodnosci z RODO)
- Przyciski Akceptuj / Odrzuc sa rownorzedne wizualnie - wymog UODO
- polityka-prywatnosci.html rozszerzona o tabele cookies

PRZYCISKI BANERA (31.07.2026)
Przyczyna: regula .cc-modal{display:flex} nadpisywala atrybut hidden.
Okno ustawien bylo niewidoczne, ale lezalo na calym ekranie
z z-index 9200 i przechwytywalo klikniecia.
Naprawione: [hidden]{display:none!important}, przelaczanie klasa
.cc-show, start po DOMContentLoaded, wlasny handler dla kazdego
przycisku.

BANER NIE POKAZYWAL SIE (31.07.2026)
Przyczyna: wybor byl juz zapisany w localStorage podczas testow.
RESET: w konsoli (F12) wpisz BAI_RESET()

TEKST ZGODY W FORMULARZU (31.07.2026)
Przyczyna: form.lead label{display:block} nadpisywala uklad flex -
tekst zwezal sie i wychodzil poza biala karte. Naprawione.

ODSTEPY I WYSRODKOWANIE (31.07.2026)
Naglowek nie dotyka juz akapitu, akapit wysrodkowany, wylaczone
dzielenie wyrazow. Stopka: 4 kolumny w jednej linii.

PRZYKLADOWY SCENARIUSZ (31.07.2026)
Dodano podstrone przyklad-scenariusz-belfer-ai.html - pelny pakiet
dydaktyczny. Przycisk w sekcji Przyklad prowadzi teraz do niej
zamiast do nieistniejacego pliku PDF.

KOMENDY KONSOLI (F12)
